# Contributing to jev-sdk

Thanks for your interest in improving **jev-sdk**! This document outlines the workflow for contributing.

## Getting Started

1. Fork the repository and clone your fork.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the dev server:
   ```bash
   npm run dev
   ```

## Development Workflow

- **Branch naming**: Use descriptive branch names like `feat/add-xyz` or `fix/issue-123`.
- **Commits**: Write clear, concise commit messages. Use the imperative mood (e.g., "Add X feature").
- **Tests**: Add tests for any new functionality. Run `npm test` before pushing.
- **Linting**: Run `npm run lint` and `npm run format` to keep the codebase clean.

## Pull Requests

1. Open a PR from your branch to `main`.
2. Describe what you changed and why.
3. Ensure CI passes (lint, build, tests).

## Code of Conduct

Be respectful and constructive. Harassment or discrimination will not be tolerated.
