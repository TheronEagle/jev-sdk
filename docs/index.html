How it works

The jev-sdk sends logs to three parallel evaluation heads:

  • Score – Blast radius (1–5)
  • Choice – Owning team (Infra, Core-API, Frontend, Security)
  • Noul – Is this a unique anomaly?

If Score > 4.0 or Security probability > 0.85, the process exits with code 1 (high-priority alert).
